## Selected Work

### ARIA — Autonomous Research Intelligence System

A multi-agent research system built with **LangGraph** for task decomposition, literature retrieval, filtering, synthesis, critique, and structured report generation.

**Python · LangGraph · FastAPI · Gemini · Groq · ChromaDB · Sentence Transformers · Docker**

### TriMind AI — RAG & Evaluation Pipeline

A modular RAG system combining **retrieval, query processing, source attribution, grounding evaluation, and reliability checks** for document-grounded generation.

**Python · LangChain · Pinecone · Gemini · FastAPI**

### FL-XAI — Federated Learning & Explainable AI

A federated framework for Parkinson's disease severity estimation under **heterogeneous, non-IID client conditions**, combining adaptive aggregation, SHAP-based interpretation, and statistical validation.

**Python · Scikit-learn · SHAP · NumPy · Pandas**

### Sunspot Forecasting

An ensemble deep-learning study benchmarking multiple architectures for **long-range sunspot time-series forecasting** using historical SILSO data.

**PyTorch · TensorFlow · PyTorch Lightning**
